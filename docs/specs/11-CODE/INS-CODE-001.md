### 앞으로 할 것

#### G 규칙 엔진 배선

근거: [[INS-MS-001#CoverageFacts.from_slots]] · [[INS-PRD-001#R10]]

**규칙은 이미 쓰여 있는데 사실이 안 들어가 절반이 못 돈다.** 슬롯에 가입일·만기일·급여/비급여 분리 금액을 추가하고 대화가 그것을 묻게 한다.

- [ ] 슬롯에 보장기간 항목 추가
- [ ] 슬롯에 급여/비급여 금액 항목 추가
- [ ] 보장기간 배제 규칙이 실제로 발화한다
- [ ] 자기부담 금액이 산출된다
- [ ] 비교의 비례 분담 금액이 채워진다

#### H 계층 정리

근거: [[INS-DOM-002]] 5장

**의도한 4계층이 네 곳에서 뒤집혀 있다.** 고치는 순서가 있다 — 공용 타입을 먼저 내려야 나머지가 풀린다.

- [ ] 슬롯·검색 필터 타입을 공용 계층으로 내린다 → `rag ↔ sessions` 순환이 풀린다
- [ ] 외부 데이터 어댑터에서 HTTP 라우터를 꺼내 `domains`로 옮긴다
- [ ] 도구 디스패처가 검색 도메인을 직접 부르지 않게 한다
- [ ] `search` 도메인을 `infrastructure`로 내리거나 `rag`에 흡수한다
- [ ] 빈 라우터 둘을 지운다
- [ ] 영역 코드를 한 곳으로 모은다 (관계형 제약 ↔ 슬롯 타입)

#### I 대화 오케스트레이션 분해

근거: [[INS-MS-001#SessionService.post_message]]

- [ ] 잡담·의도 분류를 앞단으로 분리
- [ ] 되묻기 게이팅을 정책 객체로
- [ ] 비교 경로를 별도 서비스로

#### J 운영 전환

근거: [[INS-INFRA-001]] 5장 · [[INS-API-001]] 4장

데모 범위의 결정을 되돌리는 슬라이스다. **대회 이후에 한다.**

- [ ] TLS·도메인

- [ ] 사용자에 관리자 표시를 두고 그것으로 판정
- [ ] 보안 쿠키 켜기
- [ ] 데모 공용 비밀번호 제거
- [ ] 요청 제한 적용

#### K 문서 정리

역공학을 하며 드러난 것이다.

- [ ] 환경변수 예시 파일이 **실제 설정과 달라 그대로 쓰면 기동이 실패한다**
- [ ] 폴더 구조 문서가 없는 모듈을 나열하고 있는 모듈을 빠뜨린다
- [ ] 제품 문서 기능표 14개 중 6개가 현실과 반대다
- [ ] 문서에 API 명세와 예시까지 있는 엔드포인트가 실제로 없다
- [ ] 제출용 종합 안내서의 시나리오가 폐기된 도메인 기준이다
- [ ] 진행 상태가 문서마다 다르다
